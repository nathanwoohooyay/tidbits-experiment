# League Manager
This is an application to manage a football teams across a league. The commissioner of the league can trade players to different
teams for a set amount if the teams budget allows it. Players can request trades to different teams as well. The commissioner can set up games as well.

## User Stories
1. As a commissioner, I want to be able to set the schedule for the season, so that teams know when they play
2. As a commissioner, I want to be able to move players to different teams, so that players can switch around to balance the league
3. As a commissioner, I want to be able to change a players salary, so that players that do better earn more
4. As a player, I want to be able to request a trade to a different team, so that I can go to a different team to get paid more
